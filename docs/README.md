# Documentation Module (`docs/`)

## Purpose
Central repository for academic whitepapers, formal system design documents, technical implementation specifications, and experimental roadmaps.

## Dependencies
- External Libraries: None (Markdown / PDF readers)
- Internal Modules: References all modules across the project

## Key Files
- `ROADMAP_IMPLEMENTATION_SPEC.md`: Detailed engineering and mathematical specification for Topological MAI, Bayesian U-FaceBP, ALIVE alignment, DRP/BBP-Net, and Cloud Colab training.
- `Further_Steps_From_MODEL_06_SepHead.md`: Experimental roadmap outlining the 24-step Gold Progression for balanced training, MIMIC transfer, and rPPG domain adaptation.
- `academic_paper_rppg.pdf`: Scientific research publication detailing theoretical foundations of mobile remote photoplethysmography and pulse wave velocity estimation.
- `Project_Documentation.pdf`: Auto-generated clinical and engineering system report containing architecture walkthroughs and visual benchmarks.
