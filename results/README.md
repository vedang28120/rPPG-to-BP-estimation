# Results & Experiments Module (`results/`)

## Purpose
Archives experimental benchmark logs, balancing comparison tables, and generated diagnostic figures.

## Dependencies
- External Libraries: `pandas`, `matplotlib`
- Internal Modules: Generated by `models/training/train_bp_mcd.py` and `utils/research_visualizer.py`

## Key Files
- `metrics/balancing_comparison.csv`: Tabular benchmark comparing original, moderate, and strong balancing strategies across SBP/DBP MAE, RMSE, and Pearson $r$.
- `figures/bp_distribution_histograms.png`: Diagnostic distribution plots illustrating train/val/test splits and target balance.
- `figures/ppg_visualization_report.png`: Three-tier visual report displaying raw RGB traces, raw POS projections, and 125 Hz filtered BVP waveforms.
- `figures/fig1_roi_wireframe.png`: Facial wireframe mesh highlighting upper forehead and bilateral cheek ROIs.
- `figures/fig2_signal_processing.png`: End-to-end signal processing stages (Raw RGB -> POS -> Bandpass -> Normalized BVP).
- `figures/fig3_bland_altman.png`: Bland-Altman statistical agreement plot comparing true vs. predicted blood pressure.
- `figures/fig4_correlation.png`: True vs. predicted blood pressure correlation scatter plot.
- `figures/mae_boxplot.png`: Distribution boxplots for systolic and diastolic MAE errors across subject cohorts.
