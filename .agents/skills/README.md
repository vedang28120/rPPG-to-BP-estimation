# Research & Presentation Skills Catalog

This workspace has been equipped with specialized skills to generate high-quality research papers and presentations for the rPPG to BP estimation project.

## Integrated Skills:

* **`data-storytelling`**: Transform analytical results into compelling narratives and presentation slides.
* **`mermaid-expert`**: Generate architecture diagrams, ML pipeline flowcharts, and sequence diagrams.
* **`search-specialist`**: Conduct thorough literature reviews on remote photoplethysmography and blood pressure estimation.
* **`data-scientist` / `ml-engineer`**: Expertly explain model choices, evaluation metrics, and statistical significance.
* **`docs-architect`**: Structure and draft the final comprehensive academic paper and technical reports.

To use these, simply ask the agent (e.g. "Use data-storytelling to create an outline for the presentation").
